แผนที่คอร์ส — QPU Primitives

ทุกแอปพลิเคชัน QPU มีโครงเดียวกัน 4 ขั้น — Lec01–05 ที่กำลังจะสอบ ปูฐาน ขั้น ①②④ ไว้ครบแล้ว ส่วนขั้น ③ (phase manipulation) จะไปเข้มข้นใน Lec06 เป็นต้นไป

create superposition  →  compute in superposition  ⇅  phase manipulation  →  readout
① create superposition — เอา qubit เข้าสู่ superposition (HAD คือตัวแทน) เพื่อให้มี "หลายคำตอบพร้อมกัน" ให้คำนวณ
② compute in superposition — คำนวณกับทุกความเป็นไปได้พร้อมกัน ด้วยความขนานโดยปริยายของ superposition
③ phase manipulation — จัดการเฟสเพื่อให้คำตอบที่ต้องการ โผล่ออกมาตอน READ · ขั้น ② กับ ③ มักวนสลับกันหลายรอบ (ลูกศรสองหัว)
④ readout — READ ออกมาเป็นบิตคลาสสิก · ขั้นนี้เองที่ทำให้ทุกอย่าง ก่อนหน้า "มีความหมาย" หรือ "สูญเปล่า"
ทำไมขั้น ③ ถึงมีอยู่

READ มองไม่เห็นเฟสโดยตรง — phase manipulation คือการแปลง "ข้อมูลที่ซ่อนอยู่ ในเฟส" ให้กลายเป็น "ขนาดของวง" ที่ READ เห็นได้ ไม่มีขั้นนี้ = คำนวณเสร็จแล้วอ่านผลไม่ได้

6Amplitude amplification ③ phase manipulation

8Phase estimation ③ phase manipulation
