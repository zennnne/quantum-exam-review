Qubit เดี่ยว & Bloch sphere

1. bit vs qubit · bra-ket

บิตคลาสสิกเป็นได้แค่ 0 หรือ 1 · qubit เก็บ ส่วนผสม ของทั้งสองไว้ เขียนด้วย bra-ket ว่า ∣0⟩ กับ ∣1⟩ (ket = เวกเตอร์สถานะ)

∣ψ⟩ = a∣0⟩ + b∣1⟩  ·  ∣a∣² + ∣b∣² = 1

misconception อันดับ 1

“superposition (การซ้อนทับ) = เป็น 0 และ 1 พร้อมกัน อ่านได้ทั้งคู่” → ผิด
มันคือ “ส่วนผสมที่ยังไม่มีคำตอบ” เหมือนเหรียญที่กำลังหมุนอยู่ ไม่ใช่เหรียญที่มีสองหน้าให้หยิบ — และเมื่ออ่าน (READ) qubit 1 ตัว ได้ออกมาแค่ 1 บิตธรรมดา เท่านั้น qubit จึงไม่ใช่ “ที่เก็บข้อมูล 2 เท่าฟรี”

2. amplitude = magnitude + relative phase

ค่า a, b เรียกว่า amplitude เป็นจำนวนเชิงซ้อน จึงมี 2 ลูกบิด ต่อหนึ่งวง

ลูกบิดความหมายเชิงภาพอ่าน (READ) แล้วเห็นไหม
magnitude (ขนาด ∣a∣) ความยาวเข็ม / ขนาดวงในของ circle notation เห็น — โอกาสวัดได้ = ∣a∣²
relative phase (เฟสสัมพัทธ์ θ) ทิศของเข็ม (หมุน) — ไม่เปลี่ยนความยาว ไม่เห็นตอนวัดครั้งเดียว แต่เผยตัวตอน interference (การแทรกสอด)
refresher จำนวนเชิงซ้อน

เขียนได้ 2 แบบ: a + bi (พิกัดฉาก) หรือ r·e^(iθ) (พิกัดเชิงขั้ว) — แบบหลังคือแบบที่ตรงกับเข็มนาฬิกา: r = ความยาวเข็ม (magnitude) · θ = ทิศเข็ม (phase)
ที่ต้องใช้จริงมีแค่: ∣r·e^(iθ)∣² = r² → phase ไม่กระทบโอกาสวัด

global vs relative

หมุนทุกวงด้วยมุมเท่ากัน = global phase → วัดผลอย่างไรก็เหมือนเดิม ไม่มีความหมาย
หมุนบางวงเทียบกับวงอื่น = relative phase → มีความหมาย นี่คือเหตุผลที่ PHASE หมุนแค่วง ∣1⟩ ก็พอ

3. circle notation

1 วง = 1 สถานะฐาน · ในวงมีวงในสีทึบกับเข็มหนึ่งอัน — กติกาที่ออกสอบมี 3 ข้อ

  1. รัศมีวงใน = magnitude · พื้นที่วงใน = ความน่าจะเป็น (∣a∣²) — จำเป็น “พื้นที่” ไม่ใช่ “รัศมี”
  2. ทิศเข็ม = phase · มุมบวก = ทวนเข็มนาฬิกา (convention ของวิชานี้)
  3. normalization: พื้นที่ของทุกวงรวมกัน = 1 เสมอ

4. NOT (X) และ HAD (H)

NOT / X — สลับวง ∣0⟩ ↔ ∣1⟩ (สลับทั้งขนาดและเข็ม) · เป็น its own inverse (NOT·NOT = ไม่ทำอะไร)

HAD / H — สร้าง superposition 50/50 จาก ∣0⟩ หรือ ∣1⟩ และเป็น its own inverse เหมือนกัน

H∣0⟩ = (∣0⟩ + ∣1⟩)/√2  ·  H∣1⟩ = (∣0⟩ − ∣1⟩)/√2

ทำไม H∣1⟩ ต้องมีเครื่องหมายลบ — 3 เหตุผล

1. orthogonality (ความตั้งฉาก) — ∣0⟩ กับ ∣1⟩ ตั้งฉากกัน ผลลัพธ์ H∣0⟩ กับ H∣1⟩ ก็ต้องตั้งฉากกันด้วย ลอง inner product: (1·1 + 1·(−1))/2 = 0 ✓ ถ้าเป็นบวกทั้งคู่จะไม่ตั้งฉาก

2. reversibility (ย้อนกลับได้) — ถ้า H∣0⟩ กับ H∣1⟩ ให้ผลเหมือนกันเป๊ะ ก็ย้อนกลับไม่ได้ว่ามาจากอะไร เครื่องหมายลบคือสิ่งเดียวที่แยกสองเส้นทางนี้ออกจากกัน

3. interference — พอ H อีกที เทอมบวกกับเทอมลบหักล้างกัน (destructive) เหลือ ∣0⟩ ตัวเดียว → นี่คือเหตุผลที่ H·H = ไม่ทำอะไร

ทั้งสามเรื่องนี้คือ “เครื่องหมายลบ = เข็มชี้ลง = −1 ในเวกเตอร์ = relative phase 180°” สิ่งเดียวกัน เล่า 3 ภาษา

5. READ และ WRITE

คำสั่งทำอะไรย้อนกลับได้ไหม
READ วัด → สุ่มยุบเหลือ 0 หรือ 1 ตามความน่าจะเป็น · ลบ phase ทิ้งทั้งหมด ไม่ได้ — คำสั่งเดียวในวิชานี้ที่ irreversible (และเป็นตัวเดียวที่สุ่ม)
WRITE ตั้งค่า qubit ให้เป็น ∣0⟩ หรือ ∣1⟩ แบบแน่นอน — ตั้งเป็น superposition ไม่ได้ ไม่ได้ เพราะสร้างจาก READ
WRITE สร้างจาก READ + NOT

WRITE ไม่ใช่คำสั่งพื้นฐานจริงๆ — วิธีทำคือ READ ก่อน (บังคับให้เป็น 0 หรือ 1 แน่ๆ) แล้วถ้าได้ค่าไม่ตรงที่ต้องการ ค่อย NOT · ที่ WRITE ย้อนกลับไม่ได้ก็เพราะข้างในมี READ อยู่นี่เอง

6. QRNG — โปรแกรมควอนตัมตัวแรก → ดูโค้ด

วงจรสั้นที่สุดที่มีประโยชน์จริง: WRITE(0) → HAD → READ ได้บิตสุ่มแท้ 1 บิต (ทำ 8 สายขนานกันก็ได้ random byte)

7. PHASE(θ)

หมุนเข็มเฉพาะวง ∣1⟩ ไป θ องศา (ทวนเข็ม = บวก) · ไม่มีผลกับ ∣0⟩ เลย และไม่เปลี่ยนโอกาสวัด เพราะขนาดวงเท่าเดิม

counter-example ที่ต้องจำ

PHASE เป็น reversible แต่ไม่ใช่ its own inverse — PHASE(45°) สองที = PHASE(90°) ไม่ใช่กลับที่เดิม ต้องย้อนด้วย PHASE(−θ)
ข้อยกเว้น: PHASE(180°) = Z ตัวนี้ its own inverse (เพราะ 180+180 = 360 = ครบรอบ)

สถานะที่มีชื่อ 4 ตัว สร้างจาก HAD แล้วต่อ PHASE: ∣+⟩ (0°) · ∣−⟩ (180°) · ∣+Y⟩ (+90°, เข็มชี้ซ้าย) · ∣−Y⟩ (−90°, เข็มชี้ขวา)

8. no-cloning — คำสั่งที่หายไป

the missing operation

COPY ไม่มีในโลกควอนตัม — ก๊อป qubit ที่เราไม่รู้ค่าของมันไม่ได้เลย (จะรู้ค่าต้อง READ ซึ่งทำลาย state ไปแล้ว)

ผลที่ตามมาซึ่งจะเจอทั้งวิชา: ทำ backup state ไว้กันพลาดไม่ได้ · teleportation (Lec04) จึงเป็นการ “ย้าย” ไม่ใช่ “ก๊อป” ต้นทางต้องเสียไป · และข้อจำกัดนี้กลับกลายเป็นอาวุธของ QKD คือถ้ามีสปายมาดักอ่าน จะทิ้งร่องรอยไว้เสมอ

ทำ PHASE(90°) ต่อกัน 2 ครั้งบน ∣+⟩ แล้วอ่านผล จะได้อะไร
ถูกต้อง — PHASE บวกมุมสะสม และไม่แตะขนาดวงเลย โอกาสจึงไม่ขยับ
ยังไม่ใช่ — PHASE ไม่ใช่ its own inverse (มุมสะสมเป็น 180°) และ phase ไม่เคยเปลี่ยนโอกาสวัด
คำสั่งใดใน Lec02 ที่ ย้อนกลับไม่ได้ และลบ phase ทิ้ง
ถูกต้อง — READ เป็น op เดียวที่ irreversible และเป็นตัวเดียวที่สุ่มด้วย
ยังไม่ใช่ — HAD กับ PHASE ย้อนกลับได้ทั้งคู่ (H ด้วย H เอง, PHASE ด้วย PHASE(−θ))

9. เมทริกซ์ของ gate — X = HZH และ Z = HXH

gate 1 qubit ทุกตัวเขียนเป็นเมทริกซ์ 2×2 ได้ · การ “ต่อ gate” = การคูณเมทริกซ์ โดยตัวที่ทำก่อนอยู่ขวาสุด (อ่านวงจรซ้าย→ขวา แต่เขียนสูตรขวา→ซ้าย)

H = 1√2 111−1  ·  Z = 100−1  ·  X = 0110

X = H Z H — คูณคู่ในสุดก่อน
1) Z·H = 100−1 · 1√2 111−1 = 1√2 11−11 (แถวล่างโดน −1 คูณ → สลับเครื่องหมายทั้งแถว)
2) H·(ZH) = 12 111−1 · 11−11 = 12 1−11+11+11−1 = 12 0220
3) ดึง ½ เข้าไป = 0110 = X ✔
Z = H X H — สลับที่ H กับ Z ก็ได้อีกสมการ (สไลด์ p86–90)
1) X·H = 0110 · 1√2 111−1 = 1√2 1−111 (X = สลับสองแถว)
2) H·(XH) = 12 111−1 · 1−111 = 12 1+1−1+11−1−1−1 = 12 200−2
3) ดึง ½ เข้าไป = 100−1 = Z ✔
อ่านเป็นภาษาคน — ไม่ต้องท่องเมทริกซ์

H คือตัวสลับมุมมองระหว่างแกน X กับแกน Z (ดูข้อ 11) · เอา H ประกบหน้า-หลัง gate ตัวไหน gate นั้นจะเปลี่ยนไปทำงานบนอีกแกนหนึ่งทันที
ผลที่ใช้ได้จริง: QPU ที่ไม่มีปุ่ม NOT ก็ยังพลิกบิตได้ ด้วย had() → phase(180) → had()

10. RNOT (√NOT) — gate ที่โลกคลาสสิกไม่มีวันมี

“ครึ่งหนึ่งของการพลิกบิต” ไม่มีความหมายในโลกบิต แต่มีจริงในควอนตัม เพราะ qubit เดินผ่าน superposition ได้ · RNOT ทีเดียว = หยุดครึ่งทางระหว่าง ∣0⟩ กับ ∣1⟩ (50/50) · ทำสองที = NOT เต็มตัว

√NOT = 12 1+i1−i1−i1+i  ·  สัญลักษณ์วงจร = กล่อง √X

ตรวจว่า “ทำสองที = NOT” จริงไหม — กุญแจคือ i² = −1
1) ช่องบนซ้าย = ¼[(1+i)² + (1−i)²] · (1+i)² = 1+2i−1 = 2i · (1−i)² = 1−2i−1 = −2i → รวม = 0
2) ช่องบนขวา = ¼[(1+i)(1−i) + (1−i)(1+i)] = ¼[2 + 2] = 1
3) เมทริกซ์สมมาตร → ช่องล่างได้ 1 กับ 0 เหมือนกัน → 0110 = NOT ✔
RNOT = H · PHASE(90°) · H — หน้าตาเดียวกับ X = HZH เป๊ะ แค่เปลี่ยน 180° เป็น 90°
1) P(90)·H = 100i · 1√2 111−1 = 1√2 11i−i
2) H·(P(90)H) = 12 111−1 · 11i−i = 12 1+i1−i1−i1+i = √NOT ✔

11. Bloch sphere — qubit ทั้งตัวในลูกศรอันเดียว

หัวข้อนี้เขียนยาวกว่าข้ออื่นตั้งใจ เพราะเป็นจุดที่งงกันมากที่สุดของคาบนี้ — อ่านช้าๆ ทีละหัวข้อย่อยได้เลย

ทำไมต้องมีเครื่องมือนี้อีกอัน? circle notation เก่งตอนมีหลาย qubit (2ᴺ วง) แต่ตอนมี qubit เดียว มันเปลืองพื้นที่ไปหน่อย — เพราะ qubit เดียวมีลูกบิดจริงๆ แค่ 2 ตัว ของอย่างนี้วาดเป็นจุดบนทรงกลม ได้พอดี (ลูกโลกก็ใช้ 2 ตัวเลข: ละติจูด + ลองจิจูด)

ทำไม state อยู่บน “ผิว” ทรงกลม ไม่ใช่ข้างใน

เริ่มจาก ∣ψ⟩ = a∣0⟩ + b∣1⟩ → a, b เป็นจำนวนเชิงซ้อน = 4 ตัวเลขอิสระ แล้วโดนหักออก 2 ข้อ:

1. normalization ∣a∣² + ∣b∣² = 1 บังคับอยู่แล้ว → หายไป 1 ตัว
2. global phase ไม่มีความหมาย (ข้อ 2) → หมุนทั้งคู่พร้อมกันเท่าไรก็เป็น state เดิม → หายไปอีก 1 ตัว

เหลือ 2 ตัวเลข พอดี = θ (ความสูง) + φ (ลองจิจูด) ซึ่งก็คือผิวของทรงกลมเป๊ะๆ — ไม่มี “ระยะจากจุดศูนย์กลาง” ให้เล่นเลย เพราะ normalization ล็อกความยาวลูกศรไว้ที่ 1 ตลอด
(จุดข้างในทรงกลมมีความหมายจริง เรียก mixed state แต่ไม่อยู่ในขอบเขตวิชานี้)

∣ψ⟩ = cos(θ/2)∣0⟩ + eiφ sin(θ/2)∣1⟩

11.2 gate = การหมุน (นี่คือหัวใจ)

บนทรงกลม gate ทุกตัวของ 1 qubit คือ “หมุนลูกศรรอบแกนหนึ่ง เป็นมุมหนึ่ง” เท่านั้นเอง · ทิศบวก = ทวนเข็มนาฬิกาเมื่อมองจากปลายแกนบวกย้อนลงมา (กฎมือขวา)

gateหมุนรอบแกนโอกาสวัดเปลี่ยนไหมอุปมามือ (สไลด์ p72)
ROTX(θ) แกน X (นอน) เปลี่ยน — ลูกศรไต่ขึ้นลงระหว่างขั้ว เอียงมือ ไปหน้า / มาหลัง
ROTY(θ) แกน Y (นอน) เปลี่ยน เอียงมือ ซ้าย / ขวา
PHASE(θ) = ROTZ(θ) แกน Z (ตั้ง) ไม่เปลี่ยน — ลูกศรอยู่ละติจูดเดิมตลอด หมุนมือ รอบตัวเอง (มืออยู่ที่เดิม แค่หันคนละทาง)
X (NOT) แกน X · 180° เปลี่ยน — ∣0⟩ ↔ ∣1⟩ (พลิกขั้ว) ตีลังกาหน้า-หลังครึ่งรอบ
Z = PHASE(180°) แกน Z · 180° ไม่เปลี่ยน — ∣+⟩ ↔ ∣−⟩ หมุนรอบตัวเองครึ่งรอบ
HAD แกนเฉียง (X+Z)/√2 · 180° เปลี่ยน — ∣0⟩ ↔ ∣+⟩ , ∣1⟩ ↔ ∣−⟩ สลับแกน X ↔ Z เข้าหากัน
RNOT (√X) แกน X · 90° (ครึ่งทางของ NOT) เปลี่ยน — ∣0⟩ → เส้นศูนย์สูตร (50/50) ตีลังกาแค่ครึ่งของครึ่งรอบ

เห็นด้วยตาว่าทำไม PHASE ไม่เปลี่ยนโอกาสวัด

แกน Z คือแกนตั้ง หมุนรอบมันแล้วลูกศรอยู่ละติจูดเดิมเสมอ — สูงเท่าเดิม = θ เท่าเดิม = magnitude เท่าเดิม = โอกาสวัดเท่าเดิม เปลี่ยนแค่ “หันไปทางไหน” (φ)
ส่วน ROTX / ROTY หมุนรอบแกนนอน ลูกศรเลยไต่ขึ้นลงระหว่างสองขั้ว → θ เปลี่ยน → โอกาสเปลี่ยน
⇒ กลุ่มที่เปลี่ยนโอกาสวัดได้: HAD · NOT · ROTX · ROTY · กลุ่มที่ไม่เปลี่ยน: PHASE / ROTZ

ทำไม H ถึงสลับ X กับ Z ได้ (ย้อนไปข้อ 9)

HAD คือการหมุน 180° รอบแกนเฉียงที่อยู่กึ่งกลางระหว่างแกน X กับแกน Z พอดี ผลของมันคือสลับแกน X ↔ Z · เพราะงั้น “หมุนรอบ Z” (= Z gate) เมื่อเอา H ประกบหน้า-หลัง ก็กลายเป็น “หมุนรอบ X” (= X gate) เป๊ะ → X = HZH โดยไม่ต้องท่องเมทริกซ์เลย

เพื่อให้วงจรกับ circle notation ตรงกันโดยไม่ต้องแปลง — เห็น 0x2 บนวงจร ก็เปิดตารางไบนารีดูคอลัมน์ 0x2 ได้ทันทีว่ากระทบวงไหน ถ้าตั้งชื่อ Q1/Q2/Q3 ต้องมานั่งจำอีกชั้นว่า Q2 คือน้ำหนักเท่าไร (แล้วมักสลับ)

operator pairs — gate 1 qubit ทำงานใน register ยังไง

gate 1 qubit ที่ยิงใส่ register ไม่ได้แตะทีละวง แต่แตะทีละ คู่: จับวงที่ index ต่างกันเท่าน้ำหนักบิตของ qubit ที่ยิง มาเข้าคู่กัน — 8 วง → ได้ 4 คู่เสมอ

ยิงที่คู่ของวงในตารางไบนารี
0x1 (0,1) (2,3) (4,5) (6,7) คู่ที่ต่างกันแค่คอลัมน์ 0x1
0x2 (0,2) (1,3) (4,6) (5,7) คู่ที่ต่างกันแค่คอลัมน์ 0x2
0x4 (0,4) (1,5) (2,6) (3,7) คู่ที่ต่างกันแค่คอลัมน์ 0x4
ทริกไบนารี

อย่าไล่จับคู่ทีละวง ให้มองเป็นคอลัมน์: NOT = flip คอลัมน์นั้นทั้งคอลัมน์ (0↔1 ทุกแถว) แล้วดูว่าแต่ละแถวเลื่อนไปเป็นเลขอะไร · PHASE = เลือกเฉพาะแถวที่คอลัมน์นั้นเป็น 1 · READ = แบ่งตารางเป็นสองฝั่งตามคอลัมน์นั้น

worked example — state ตั้งต้นชุดเดียว ใช้ทั้ง 3 แบบ

สมมติ register 3 qubit อยู่ที่ |1⟩, |2⟩, |4⟩, |7⟩ อย่างละ 25% (วงเท่ากัน 4 วง เข็มชี้ขึ้นหมด):

(ก) NOT ที่ 0x1 — สลับของในแต่ละคู่

คู่ของ 0x1 = (0,1) (2,3) (4,5) (6,7) → ของในวง สลับที่กัน ทั้งขนาดและเข็ม ในตารางไบนารีคือ flip คอลัมน์ 0x1: 1→0, 2→3, 4→5, 7→6 → ดูโค้ด

จำคู่กันไว้

NOT ขยับของ (วงย้ายที่) แต่ PHASE ไม่ขยับของ (วงอยู่ที่เดิม หมุนแค่เข็ม) → ความน่าจะเป็นของทุกผลลัพธ์หลัง PHASE ยังเท่าเดิมเป๊ะ

(ข) PHASE(45°) ที่ 0x2 — หมุนเข็มของ "ฝั่งขวา" ของทุกคู่

คู่ของ 0x2 = (0,2) (1,3) (4,6) (5,7) — สมาชิกที่ index มากกว่าในแต่ละคู่คือตัวที่บิต 0x2 = 1 กลุ่มนั้นคือ |2⟩ |3⟩ |6⟩ |7⟩ ได้เข็มหมุน 45° ทวนเข็ม ที่เหลือไม่แตะ → ดูโค้ด

ทำไม PHASE แตะครึ่งหนึ่ง "เสมอ"

เพราะทุกวงถูกจับคู่หมด และในทุกคู่มีตัวที่บิตนั้นเป็น 1 อยู่ ตัวเดียว → กลุ่ม "บิตนั้น = 1" มี 2ᴺ⁄2 วง = ครึ่งพอดี ไม่ว่ายิงที่ qubit ไหนหรือ register ใหญ่แค่ไหน (ที่ 3 qubit ก็คือ 4 จาก 8 วง แม้บางวงจะว่างอยู่ก็ถือว่าถูกแตะ)

(ค) READ ที่ 0x4 — ตัดครึ่งที่ขัดกับผล แล้ว renormalize

READ ไม่ได้ทำทีละคู่แบบ NOT/PHASE แต่ใช้การแบ่งกลุ่มชุดเดียวกัน: ฝั่ง 0x4 = 0 คือ |0⟩–|3⟩ · ฝั่ง 0x4 = 1 คือ |4⟩–|7⟩ → ดูโค้ด

1 P(อ่านได้ 0) = ผลรวมพื้นที่ฝั่ง 0x4=0 = |1⟩ 25% + |2⟩ 25% = 50%
2 P(อ่านได้ 1) = |4⟩ 25% + |7⟩ 25% = 50%
3 สมมติอ่านได้ 1 → วงฝั่ง 0x4=0 (|0⟩–|3⟩) หายหมด
4 renormalize: ที่เหลือรวมได้ 50% ต้องดันกลับเป็น 100% → หารด้วย 0.5 ทุกวง → |4⟩ 50%, |7⟩ 50%
ระวัง

READ qubit เดียว ไม่ยุบทั้ง register — 0x1 กับ 0x2 ยังซ้อนทับอยู่ (|4⟩ กับ |7⟩ ยังต่างกัน) มันแค่ตัดความเป็นไปได้ครึ่งหนึ่งทิ้ง แล้วเกลี่ยส่วนที่เหลือใหม่

gateทำอะไรกับคู่แตะกี่วงความน่าจะเป็นเปลี่ยนไหม
NOT สลับของสองฝั่งของทุกคู่ ทุกวง (8) ย้ายที่ แต่ค่ารวมเท่าเดิม
PHASE หมุนเข็มฝั่งที่บิต = 1 ครึ่งเดียว (4) ไม่เปลี่ยนเลย
READ เลือกฝั่งเดียวของทุกคู่ ทิ้งอีกฝั่ง ลบทิ้งครึ่งหนึ่ง (4) เปลี่ยน — ต้อง renormalize

ทวนเร็ว: register 4 qubit ยิง PHASE(90°) ที่ 0x8 กระทบกี่วง และวงไหนบ้าง?

4 qubit = 16 วง → กระทบครึ่งหนึ่ง = 8 วง คือกลุ่มที่บิต 0x8 = 1 นั่นคือ |8⟩ ถึง |15⟩ (ค่าตั้งแต่ 8 ขึ้นไปคือค่าที่บิตน้ำหนัก 8 ติดอยู่) — ความน่าจะเป็นทุกวงเท่าเดิม

register 3 qubit ยิง NOT ที่ 0x4 ตอนตั้งต้นอยู่ที่ |1⟩ 100% จะไปอยู่ที่วงไหน?
ถูก — flip คอลัมน์ 0x4 ของแถว 001 ได้ 101 = |5⟩ (คู่ของ 0x4 คือ (1,5))
ยัง — NOT ที่ 0x4 จับคู่ (0,4) (1,5) (2,6) (3,7) → |1⟩ ไปที่ |5⟩ (บวก/ลบ 4 นั่นเอง)
state (|000⟩+|111⟩)/√2 อธิบายให้ตรงตามภาษาที่ออกสอบ ควรพูดว่ายังไง?
ใช่ — superposition = สมบัติ qubit เดี่ยว / entanglement = สมบัติของทั้งระบบ
ไม่ใช่ — GHZ ให้ผลได้แค่ 000 กับ 111 ไม่มีทางได้ 010 → แยกทีละ qubit ไม่ได้ = entangle (และ 3 qubit ต้องวาด 8 วงเสมอ)

if (send_had == recv_had)      // ฐานตรงกัน

จุดที่คนมักพลาด

  • Lec01 · QPU คืออะไร — “QPU มาแทน CPU / เร็วกว่าทุกงาน” ผิด มันคือ co-processor ที่เก่งบางงาน
  • Lec01 · QPU คืออะไร — “ต้องเก่งฟิสิกส์ก่อนถึงเขียนโปรแกรมได้” ผิด (สไลด์เทียบกับ C++ กับทรานซิสเตอร์)
  • Lec02 · ข้อ 1 bit vs qubit — “superposition = เป็น 0 และ 1 พร้อมกัน อ่านได้ทั้งคู่” ผิด · qubit 1 ตัวอ่านได้ 1 บิตเท่านั้น
  • Lec02 · ข้อ 2 amplitude — “phase เปลี่ยน → โอกาสวัดเปลี่ยน” ผิด phase ไม่แตะ magnitude² · กับดักหลักของ Lec02
  • Lec02 · ข้อ 3 circle notation — จำผิดว่า “รัศมี = ความน่าจะเป็น” ของจริงคือ พื้นที่
  • Lec02 · ข้อ 5 READ/WRITE — “WRITE ตั้ง superposition ได้” ผิด ตั้งได้แค่ ∣0⟩ / ∣1⟩
  • Lec02 · ข้อ 6 QRNG — “รัน QRNG บน simulator = สุ่มแท้” ผิด simulator ยังใช้ PRNG

  • Lec02 · ข้อ 9 เมทริกซ์ — คูณผิดลำดับ · gate ที่ทำก่อนต้องอยู่ขวาสุด (วงจรอ่านซ้าย→ขวา แต่สูตรคูณขวา→ซ้าย)

  • Lec02 · ข้อ 12 Spy Hunter — สรุปว่า “ค่าไม่ตรง = มีสปาย” · ต้อง HAD ตรงกันด้วย ถ้าฐานไม่ตรงให้ทิ้งทุกกรณี
